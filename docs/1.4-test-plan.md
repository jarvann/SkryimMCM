# 1.4 test plan (one round)

Everything below is deployed and compiles but hasn't run in the game yet. Restart Claude Desktop first (new tools and
descriptions). Make a game-menu save before starting; finish on a game-menu save. Use a throwaway character for steps 3-5
where you can.

## 1. Teleport loading screen (FEAT-258, experiment)

From Solitude (Winking Skeever), each time note: frozen frame, black screen, real loading screen (picture and tip), how
long, whether the game ends up stuck in a loading screen.

1. `Teleport("riverwood")` (method coc, as before), then `Teleport("back")`.
2. `Teleport("riverwood", method: "center")`, then back.
3. `Teleport("riverwood", method: "loadingscreen")`, then back. If the loading screen stays up, say so: the tool closes it
   after arrival; if it's still stuck, `ExecuteConsoleCommand` is not the way out, reload instead.
4. Same three for an interior: `Teleport("BreezehomeInterior"...)` or any interior cell ID.

## 2. Safety and small fixes

1. Call any tool with a wrong parameter name (for example `ListSaves(Limit: 5)`): expect "has no parameter 'Limit' (did you
   mean 'limit'?)" (BUG-023).
2. If MCM Recorder is installed: start a recording playback, then try `StudioGo` or `CaptureFace` during it: expect a refusal
   naming the recording (FEAT-261).
3. On the Turn Undead item from 2026-11-16 (if still around), `GetEnchantmentInfo`: report magnitude, noMagnitude,
   archetype and descriptionTemplate next to what the item card shows (BUG-025).

## 3. Blueprint export (FEAT-121, FEAT-263)

On Arya: `GetCharacterBlueprint(outputPath: ...)`. Check: `quests.stagesSource` names a save made just now; quests carry
`stagesDone`; shout words carry `unlocked`.

## 4. Blueprint apply of stats (FEAT-121)

On the other character: `ApplyBlueprint(path, sections: "skills,level,perks,spells,shouts")` dry run, then `dryRun: false`.
Check skills, level, perks, spells, shouts and words in the game menus.

## 5. Quest replay (FEAT-263)

1. `ReplayQuests(path, quests: "list")`.
2. Pick one simple miscellaneous quest: preview, then `confirm: true, previewSave: <the preview's save>`.
3. Check the journal, the stage and any reward; report a stage the game refused. Load the way-back save afterwards if it
   misfired.

## 6. Save migration check (FEAT-269)

1. `CompareSaveToLoadOrder("<today's newest save>", scripts: true)`: expect 0 removed and few or no script changes.
2. `CompareSaveToLoadOrder("<a save from July, if moved back from SkyLink_Archive or _Backup>", scripts: true)`: expect
   about 2,000 removed plugins, ~135 high risk, ~290 scripts with removed or retyped variables. Tell me if the report reads
   clearly enough to decide from.

## 7. Wrap up

`ArchiveSaves("skylink")` dry run, then move the round's saves if you like. Finish on a game-menu save.
