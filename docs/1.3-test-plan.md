# 1.3: in-game test plan

Tests for what 1.3 adds, in the order that needs the fewest restarts. Each step names the tool to
call and what a pass looks like. Results go in `project_work_items.json` under each item's history.

Already passed (2026-11-15/16): RunSelfTest 24/24, EquipItems (except the right hand),
GetMenuState, GetLoadOrder, GetHairAndSkinColor, SetHairColor/SetSkinTone, GetCrashLog,
settings and config tools, notes, WaitForSkyrim, TransferItems (all four cases), LootBodies on
build 8.

## Before you start

- Quit Claude Desktop from the tray and reopen it, so it reads the new tool list
  (a new chat is not enough).
- For part B, close Skyrim, run `.\build_plugin.ps1 -Deploy` (the host DLL only deploys with
  the game closed), then start the game.

## A. With the game running (no restart)

1. **LootBodies on build 9 (FEAT-218).** Kill two or three armed NPCs, stand by the bodies.
   - `LootBodies dryRun=true`: worn armor and weapons are listed with `equipped:true`;
     `bodiesInRange` and `bodiesWithLoot` are set; `bodiesLooted` is 0.
   - `LootBodies categories=all dryRun=true`: no entry has a FormID for a name or a value of -1;
     `totalValue` equals the sum of the listed values.
   - `LootBodies includeGold=false`, then a real run with `categories=all`: the bodies end up
     empty except for hidden items; a second dry run finds nothing.
   - Walk away from any bodies and run it again: `message` says no bodies are in range.
2. **Right hand (FEAT-205).** `AddItem 00012EB7` (Iron Sword), `EquipItems` it with
   `hand=right`, check `GetEquippedItems`, put back what you had, `RemoveItem` the sword.
3. **Head parts (FEAT-208).** Note the current parts with `GetAppearance`.
   - `ListHeadPartChoices type=eyebrows`, then `SetHeadPart type=eyebrows index=<another>`:
     the brows change (try `refresh=true` if they don't). The reply's `previous` is the old part.
   - `RemoveHeadPart type=scar` (or `type=facialHair` on a male character), `refresh=true`.
   - `SetHeadPart part=<previous formId>` puts each one back.
   - Save, load: the restored parts are still there.
   - `RemoveHeadPart type=eyes`: refused.
4. **Hair index (FEAT-209).** In RaceMenu, eyes read 96 and brows 165 (or whatever
   `GetAppearance` reports after step 3). `ListHeadPartChoices type=hair start=1390`: find the two
   hairs RaceMenu has that the list doesn't.
5. **Hair and skin after save/load (FEAT-226).** Change both, save, load, check, put them back
   (hair FE0C9801, skin #B9B3AA).
6. **Script stats (FEAT-150).** `GetScriptStats`: `runningStacks`, `stacksByState` and the
   three top lists are filled in and the script names look like real mod scripts.
   `GetScriptStats samples=10`: totals are summed with averages. Run it once in a busy town and
   once in an empty interior: the town shows more stacks.
7. **Blueprint (FEAT-206/207).**
   - `GetCharacterBlueprint outputPath=<Documents>\SkyLinkAI\bp-test.json`: open the file;
     form IDs have a `formIdSource` with a plugin and local ID; `formatVersion` is 2.
   - Drop or sell a few items, spend some gold, unequip your armor.
   - `ApplyBlueprint path=<that file>` (dry run by default): it lists exactly the missing items,
     the gold change and the equipment.
   - `ApplyBlueprint dryRun=false`: the items and gold come back and the armor is worn.
   - Run it again: nothing left to add.
8. **Guidebook (FEAT-221).** Ask Claude a game question ("what does Blessing of Nature do?",
   "how do I start Diplomatic Immunity?"). It should call SearchGuidebook and GetGuidebookPage
   on its own and name the UESP page. Try one offline (Wi-Fi off): it says it is answering from
   memory.
9. **Event backlog (INFRA-015).** After 20+ minutes of play, `PollEvents`: at most 50
   events, a `remaining` count, and quest or lock churn summed into single events.

## B. After a game restart (host DLL)

10. **Reconnect with a write first (INFRA-018).** With Claude Desktop open and the game running,
    note your gold. Quit Skyrim to the desktop and start it again; load the save. Before any
    other call, ask Claude to `AddItem 0000000F 1` (one gold). Pass: the call succeeds without an
    error and gold went up by exactly 1 (not 2). Repeat once with a read first (`GetPlayerInfo`)
    to confirm that path still works.
11. **Unnamed quests in events.** Start or advance a quest that has no name; the event shows
    the editor ID or "unnamed quest (FormID)", not a bare FormID.
12. **Crash recorder (FEAT-219).** Play a few minutes, then quit normally: `GetCrashLog` reports
    the last session as a clean exit. To see a crash entry, use the next real crash: after it,
    `GetCrashLog` shows the recorder's last entries next to the Crash Logger report.
13. **Connection diagnostics (BUG-012).** `CheckConnection`: shows the store (Steam), the game
    version, the Address Library file, and game-thread counters with tasks completed > 0.

## C. Release check

14. Build the release zip, install it in MO2 with a fresh profile (the 1.2.1 packaging problem),
    start the game, `RunSelfTest`.
